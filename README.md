# Hedge Fund — 소액 퀀트 자동매매 시스템

100만원(~$750)으로 시작하는 자동화된 퀀트 헤지펀드 시스템.
**목표는 수익 극대화가 아니라 시장에서의 생존(자본 보존 우선, 성장 차선)**.

3개의 비상관 전략을 동시 운용하여 단일 전략 실패 리스크를 분산하고,
엄격한 리스크 관리 규칙으로 자본을 보호합니다.

---

## 시스템 개요

```
[Upbit API]     [Alpaca API]     [yfinance]
     │               │               │
     └───────┬───────┘───────┬───────┘
             │               │
         ┌───▼───┐     ┌────▼────┐
         │ Data  │     │  Data   │
         │Upbit  │     │yfinance │
         └───┬───┘     └────┬────┘
             │              │
     ┌───────▼──────────────▼────────┐
     │         Strategy Engine        │
     │  A: Crypto Momentum (35%)     │
     │  B: ETF Mean Reversion (35%) │
     │  C: Dual Momentum (30%)      │
     └──────────────┬────────────────┘
                    │ Signals
              ┌─────▼──────┐
              │    Risk     │
              │  Manager    │
              └─────┬──────┘
                    │ Approved Orders
           ┌────────▼─────────┐
           │   Order Builder   │
           │ Signal → Order    │
           └────────┬─────────┘
                    │
        ┌───────────▼───────────┐
        │     Executors          │
        │  Paper │ Upbit │ Alpaca│
        └───────────┬───────────┘
                    │
              ┌─────▼──────┐
              │  Portfolio  │
              │  Manager    │
              │ (run_cycle) │
              └─────┬──────┘
                    │
              ┌─────▼──────┐
              │  Scheduler  │
              │ (APScheduler)│
              └────────────┘
```

**실행 사이클 (run_cycle)**:
1. 포트폴리오 현재가치 조회
2. 드로다운 체크 (20% 초과 시 전체 거래 중단)
3. 각 전략에서 매매 시그널 생성
4. 목표 포지션 가치 계산
5. 시그널 → 주문 변환
6. 주문별 리스크 체크
7. 주문 실행
8. 포트폴리오 상태 업데이트

## 전략 상세

### 전략 A: 암호화폐 모멘텀 (35% 배분)

**원리**: 최근 가격이 많이 오른 코인이 단기적으로 계속 오르는 경향(모멘텀 프리미엄)을 이용합니다.

| 항목 | 값 |
|------|-----|
| 거래소 | Upbit (KRW 마켓) |
| 유니버스 | KRW 거래량 상위 15개 코인 |
| 리밸런싱 | **주간** (7일마다) |
| 측정 기간 | 20일 |

**매수 규칙**:
1. 유니버스 내 각 코인의 **20일 모멘텀**(= 20일 전 대비 수익률)을 계산
2. 모멘텀이 **양수**인 코인 중 **상위 3개**를 선택
3. 선택된 코인에 **균등 배분** (각 1/3씩)
4. 시그널 강도는 min-max 정규화 (0~1)

**매도 규칙**:
- 모멘텀 순위에서 **상위 3개 밖으로 밀려나면** 해당 코인 전량 매도
- 모멘텀이 **음수**가 되면 보유 여부와 무관하게 매도

**회전 주기**:
- 7일 간격으로만 리밸런싱 (사이 기간은 기존 포지션 유지)
- 주간 리밸런싱으로 거래 비용 최소화 (일간 대비 회전율 1/7)

**예시**:
```
유니버스: [BTC, ETH, XRP, SOL, ADA, DOGE, ...]

20일 모멘텀:
  BTC: +15.3%  ← 1위 → 매수 (1/3 배분)
  SOL: +12.1%  ← 2위 → 매수 (1/3 배분)
  ETH:  +8.7%  ← 3위 → 매수 (1/3 배분)
  XRP:  +2.1%  ← 4위 → 매도 (보유 시)
  ADA:  -3.5%  ← 음수 → 매도 (보유 시)
```

### 전략 B: 미국 ETF 평균회귀 (35% 배분)

**원리**: ETF 가격이 평균에서 크게 벗어나면 다시 돌아오는 경향(평균회귀)을 이용합니다.
기관투자자의 분기말/월말 리밸런싱으로 일시적 가격 왜곡이 발생하고, 이후 정상으로 복귀합니다.

| 항목 | 값 |
|------|-----|
| 거래소 | Alpaca (미국 시장) |
| 유니버스 | SPY, QQQ, TLT, GLD, IEF |
| 리밸런싱 | **매일 체크**, 조건 충족 시 즉시 진입/청산 |
| 측정 기간 | 20일 |

**핵심 지표 — z-score**:
```
z-score = (최근 20일 누적 로그수익률 - 기대값) / 표준편차
```
- z-score가 **-1.5 이하**: 20일간 비정상적으로 많이 하락함 (과매도)
- z-score가 **+1.5 이상**: 20일간 비정상적으로 많이 상승함 (과매수)

**매수 규칙**:
- z-score ≤ **-1.5** → **매수** (과매도 상태, 평균으로 복귀 기대)
- 시그널 강도: z-score가 깊을수록 강함 (z=-3.0에서 최대)

**매도 규칙**:
- z-score ≥ **+1.5** → **전량 매도** (과매수 상태, 하락 기대)
- z-score가 -1.5 ~ +1.5 사이: **현상 유지** (보유 중이면 유지, 없으면 관망)

**예시**:
```
현재 z-score:
  SPY: -1.8  → 매수 (최근 20일 과매도)
  QQQ: -0.3  → 유지 (중립)
  TLT: +1.7  → 매도 (최근 20일 과매수)
  GLD: -2.1  → 매수 (심한 과매도 → 강한 시그널)
  IEF: +0.5  → 유지 (중립)

→ SPY와 GLD 2종목에 균등 배분 (각 50%)
```

### 전략 C: 듀얼 모멘텀 (30% 배분)

**원리**: Gary Antonacci의 듀얼 모멘텀 이론 기반.
"절대 모멘텀"(상승 추세인가?)과 "상대 모멘텀"(어느 자산이 더 강한가?)을 결합하여,
시장이 좋을 때는 공격적 자산에 투자하고, 나쁠 때는 안전 자산으로 회피합니다.

| 항목 | 값 |
|------|-----|
| 거래소 | Upbit + Alpaca (크로스 마켓) |
| 공격 자산 | BTC/KRW, SPY |
| 방어 자산 | TLT (미국 장기 국채 ETF) |
| 리밸런싱 | **월간** (매월 1일) |
| 측정 기간 | 60일 |

**의사결정 트리**:

```
             60일 수익률 계산
            ┌─────┴─────┐
         BTC > 0?     SPY > 0?
            │             │
    ┌───────▼───────┐  ┌──▼──┐
    │  BTC와 SPY    │  │     │
    │  둘 다 양수?  │  │     │
    └───────┬───────┘  └─────┘
            │
     ┌──────┴──────┐
     ▼             ▼
  둘 다 양수    하나만 양수    둘 다 음수
     │             │             │
     ▼             ▼             ▼
 수익률 높은    양수인 쪽에    TLT에
 쪽에 100%      100% 투자     100% 투자
```

**규칙 요약**:

| BTC 60일 수익률 | SPY 60일 수익률 | 행동 |
|:---:|:---:|---|
| +15% | +8% | **BTC 100%** (둘 다 양수, BTC가 승자) |
| +5% | +12% | **SPY 100%** (둘 다 양수, SPY가 승자) |
| +10% | -3% | **BTC 100%** (BTC만 양수) |
| -5% | +7% | **SPY 100%** (SPY만 양수) |
| -8% | -4% | **TLT 100%** (둘 다 음수 → 방어 모드) |

**특징**:
- 한 번에 **단 1개 자산**에만 100% 집중 투자
- 월 1회만 리밸런싱 → 거래 비용 극소화
- 시장 하락기에 자동으로 채권(TLT)으로 전환하여 자본 보존

## 리스크 관리 규칙

모든 주문은 Risk Manager를 통과해야 실행됩니다. 아래 규칙은 **전략 시그널보다 우선**합니다.

### 하드 리밋 (위반 시 자동 조치)

| 규칙 | 한도 | 위반 시 |
|------|:---:|---------|
| 최대 포트폴리오 드로다운 | **20%** | 전 포지션 매매 중단 |
| 최대 단일 포지션 비중 | **15%** | 해당 주문 거부 |
| 최대 단일 전략 비중 | **40%** | 해당 주문 거부 |
| 일일 VaR (95% 신뢰도) | **2%** | 경고 + 신규 매수 중단 |
| 거래당 손절 | **3%** | 기계적 매도 |
| 레버리지 | **1.0x** | 현물만 (레버리지 불가) |

### 드로다운 기반 포지션 감소

고점 대비 손실이 커질수록 **점진적으로 포지션을 줄입니다**:

```
고점 대비 손실    포지션 규모    상태
─────────────    ──────────    ────────
  0% ~  5%       100%          정상 운영
  5% ~ 10%        75%          조기 경고
 10% ~ 15%        50%          포지션 절반 감소
 15% ~ 20%        25%          최소 포지션
    > 20%           0%          전체 매매 중단
```

**예시**: 포트폴리오가 100만원 → 88만원으로 하락 (12% 드로다운)
- 전략 A가 35만원 매수 시그널 생성 → 실제 매수액: 35만원 × 50% = **17.5만원**

### 포지션 사이징 — Quarter-Kelly

풀 켈리(Full Kelly)는 이론적 최적이나 소액 계정에서는 변동성이 너무 큼.
**Quarter-Kelly**(풀 켈리의 25%)를 사용하여 성장률의 75%를 희생하는 대신 최대 손실을 75% 줄입니다.

```
Kelly% = (승률 × 평균수익 - 패률 × 평균손실) / 평균수익
Quarter-Kelly = Kelly% × 0.25

상한: 25% (자본의 최대 25%까지만 단일 베팅)
```

### 변동성 스케일링

변동성이 높아지면 포지션 크기를 **자동으로 줄입니다**:

```
조정된 포지션 = 기본 포지션 × min(목표 변동성 / 현재 변동성, 1.0)
```
- 목표 변동성: 연율 15%
- 현재 변동성이 30%라면 → 포지션 50%로 축소

## 백테스트 검증 기준 (Go/No-Go)

실거래 전 각 전략이 반드시 통과해야 하는 기준:

| 지표 | 최소 기준 | 의미 |
|------|:---:|------|
| OOS Sharpe Ratio | > 0.8 | 위험 대비 수익 충분 |
| Max Drawdown | < 20% | 최대 손실 제한 |
| Profit Factor | > 1.3 | 총이익 / 총손실 > 1.3배 |
| Deflated Sharpe p-value | > 0.95 | 다중 검정 보정 후에도 유의미 |
| 전략 간 상관관계 | < 0.3 | 충분한 분산 효과 |

추가 검증:
- Walk-Forward 검증 (IS 30% / OOS 10% 롤링 윈도우)
- 파라미터 ±20% 변경에도 성과 유지 (과적합 방지)
- 최소 4주 페이퍼 트레이딩 후 실거래 전환
